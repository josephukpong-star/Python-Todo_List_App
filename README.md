# 📝 Python To-Do List Application

A feature-rich command-line To-Do List application built with Python as part of my Python Automation Bootcamp.

This project helps users manage daily tasks by allowing them to add, edit, search, complete, delete, sort, import, export, and generate reports for tasks. The application stores data permanently using JSON, ensuring tasks remain available after closing the program.

---

## 🚀 Features

- View all tasks
- Add new tasks
- Edit existing tasks
- Search tasks by keyword
- Mark tasks as completed
- Delete tasks with confirmation
- Show task statistics
- Calculate completion percentage
- Sort tasks alphabetically
- Sort tasks by completion status
- Export tasks to a text file
- Import tasks from a text file
- Generate task reports
- Save tasks automatically using JSON
- Input validation and error handling

## ▶️ How to Run

1. Clone this repository

```bash
git clone https://github.com/josephukpong-star/Python-Todo_List_App.git
```

2. Open the project folder

```bash
cd Python-Todo_List_App
```

3. Run the application

```bash
python main.py
```
